# Especificação do Sudoku

Repositório do trabalho da disciplina de Paradigmas de Programação, no qual um mesmo problema será resolvido utilizando os quatro paradigmas estudados: **imperativo**, **orientado a objetos**, **funcional** e **lógico**.

## Problema escolhido

**Resolvedor de Sudoku** — dado um tabuleiro 9x9 parcialmente preenchido, o sistema deve validar, resolver e/ou verificar soluções, respeitando as regras clássicas do jogo (sem repetição em linhas, colunas e blocos 3x3).
